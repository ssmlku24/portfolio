# Портфоліо Альони Чучупалової

Персональний портфоліо-сайт фронтенд-розробниці.

## Структура проєкту

```
portfolio/
├── .gitignore
├── README.md
├── index.html          # Головна сторінка
├── about.html          # Сторінка "Про мене"
├── contacts.html       # Сторінка контактів
├── styles.css          # Зовнішні стилі (Лаб. 2)
├── images/             # Папка з зображеннями
├── video/              # Папка з відео
```

## Сторінки сайту

### 1. Головна (index.html)

- Привітання та загальна інформація
- Ключові навички
- Цілі розвитку
- Фото профілю та відео з підписом

### 2. Про мене (about.html)

- Детальна інформація про автора
- Освіта та сертифікації
- Таблиця технічних навичок
- Список інтересів

### 3. Контакти (contacts.html)

- Контактна інформація
- Email та телефон
- Форма зворотного зв'язку з усіма необхідними полями

## Використані технології

- HTML5 (семантичні теги, мультимедіа, таблиці, форми)
- CSS3 (зовнішній файл `styles.css`, селектори, Box Model, позиціонування, типографіка)
- Адаптивна верстка (CSS Grid, Flexbox, Mobile First, media queries, CSS-змінні, анімації)
- Google Fonts (Inter)
- Git та GitHub (контроль версій, Conventional Commits)
